7. ECONOMIC AND CAPACITY FRAMEWORK ANALYSIS¶

Framework Overview¶

Framework A — Economic Optimisation (Unconstrained Capacity)¶

Given the input features, the model estimates the probability of fraud, $p(\text{fraud})$, for every transaction.

The Expected Financial Loss (EFL) is then computed as:

$$ EFL_i = p_i \times TransactionAmt_i $$

A transaction is selected for manual review whenever:

$$ EFL_i \geq C_{MR} $$

This replaces a traditional probability threshold with a cost-based decision rule, directly linking model predictions to the economic cost of manual review and missed fraud.

Framework B — Capacity-Constrained Prioritisation (Top-K)¶

From all economically justified transactions $(EFL \geq C_{MR})$, transactions are ranked by Expected Financial Loss. Only the top-$K$ transactions are reviewed according to the available operational capacity.

Cost Matrix¶

Outcome Cost
$C_{TP}$ — Reviewed transaction → fraud confirmed $C_{MR}$
$C_{FP}$ — Reviewed transaction → legitimate $C_{MR}$
$C_{TN}$ — Legitimate transaction not reviewed $0$
$C_{FN}$ — Fraud missed $TransactionAmt_i$

Financial Metrics¶

$$ \text{Avoided Losses} = \sum TransactionAmt_i \quad \text{for TP} $$

$$ \text{Review Cost} = (TP + FP) \times C_{MR} $$

$$ \text{Missed Fraud Losses} = \sum TransactionAmt_i \quad \text{for FN} $$

$$ \text{Net Saving} = \text{Avoided Losses} - \text{Review Cost} $$

$$ \text{Total Cost} = \text{Review Cost} + \text{Missed Fraud Losses} $$

Framework Questions¶

Framework A answers:

Which transactions are economically worth reviewing?

Framework B answers:

Given limited analyst capacity, which economically justified transactions should be reviewed first?

def evaluate(y_test, y_pred, amt_test, c_mr):

    TP = int(((y_pred == 1) & (y_test == 1)).sum())
    FP = int(((y_pred == 1) & (y_test == 0)).sum())
    FN = int(((y_pred == 0) & (y_test == 1)).sum())
    TN = int(((y_pred == 0) & (y_test == 0)).sum())

    avoided = float(
        amt_test[(y_pred == 1) & (y_test == 1)].sum()
    )

    fn_loss = float(
        amt_test[(y_pred == 0) & (y_test == 1)].sum()
    )

    rev_cost = (TP + FP) * c_mr

    net_sav = avoided - rev_cost

    tot_cost = rev_cost + fn_loss

    return {

        "TP": TP,
        "FP": FP,
        "FN": FN,
        "TN": TN,

        "reviews": TP + FP,

        "avoided_losses": round(avoided, 0),
        "fn_losses": round(fn_loss, 0),
        "review_cost": round(rev_cost, 0),
        "net_saving": round(net_sav, 0),
        "total_cost": round(tot_cost, 0),

        "pct_recovered": round(
            net_sav / baseline_loss * 100,
            2
        ),

        "avg_per_review": round(
            avoided / (TP + FP),
            2
        ) if (TP + FP) > 0 else 0,

        "precision": round(
            TP / (TP + FP),
            4
        ) if (TP + FP) > 0 else 0,

        "recall": round(
            TP / (TP + FN),
            4
        ) if (TP + FN) > 0 else 0,
    }

7.1 Framework A — Economic selection by Expected Financial Loss, without review capacity constractions¶

For each manual review cost ($C_{MR}$), every transaction whose Expected Financial Loss (EFL) is greater than or equal to the manual review cost is selected for review.

$$ EFL_i = p(\text{fraud})_i \times TransactionAmt_i $$

Therefore, the economic selection rule is:

$$ EFL_i \geq C_{MR} $$

cap_results = {}

for c_mr in C_MR_SCENARIOS:

    # Economically justified transactions
    eligible = (efl >= c_mr)
    eligible_idx = np.where(eligible)[0]

    # Rank by Expected Financial Loss
    sorted_idx = eligible_idx[np.argsort(efl[eligible_idx])[::-1]]

    eligible_reviews = len(sorted_idx)

    # Reference line for elbow calculation

    x1, y1 = x[0], y[0]

    x2, y2 = x[-1], y[-1]


    #  Distance from each point to reference line

    distances = np.abs(
        (y2 - y1) * x
        - (x2 - x1) * y
        + x2 * y1
        - y2 * x1

        (y2 - y1) ** 2
        + (x2 - x1) ** 2

Interpretation¶

Framework A establishes the economic boundary for manual review by selecting all transactions for which Expected Financial Loss (EFL) is greater than or equal to the manual review cost. This provides an economically justified review volume for each manual review cost scenario without imposing an operational capacity constraint.

The results show a clear relationship between manual review cost and the economically justified review volume. As C_MR increases from USD 3 to USD 20, the number of economically justified reviews decreases from 105,910 to 25,620 transactions, as fewer transactions satisfy the EFL ≥ C_MR selection rule. Despite this reduction in review volume, the strategy remains economically attractive across all scenarios. Net savings range from USD 2.67 million at C_MR = USD 3 to USD 1.85 million at C_MR = USD 20, while fraud-loss recovery ranges from 83.7% to 57.8% of the baseline fraud loss. This demonstrates that the EFL-based economic selection remains effective even as the cost of manual investigation increases.

However, Framework A assumes that the organisation can review all economically justified transactions. In practice, operational constraints such as investigator availability, workload and processing capacity may prevent this. This motivates Framework B, which addresses the question of which transactions should be reviewed first when available capacity is limited.

Framework B prioritises transactions by Expected Financial Loss (EFL), calculated as the predicted probability of fraud multiplied by the transaction amount. Rather than applying a binary fraud threshold, transactions are ranked from highest to lowest expected financial impact. The highest-EFL transactions are therefore reviewed first, ensuring that limited manual review capacity is allocated to cases with the greatest potential economic impact.

Across all manual review cost scenarios, the net-saving curves increase rapidly at low review volumes and progressively flatten as capacity expands, indicating clear diminishing marginal returns.

The elbow criterion identifies practical operating points before the unconstrained economic optimum is reached. For example, when C_MR = USD 3, the elbow occurs at approximately 18,250 reviews, corresponding to only 3.09% of all transactions, while capturing 64.7% of total EFL (approximately USD 2.16 million). The corresponding Framework A optimum requires 105,910 reviews (17.93% of transactions). At this point, the EFL ranking captures 90.3% of total EFL, while Framework A generates a maximum net saving of approximately USD 2.67 million.

The difference between these operating points is substantial. Reaching the Framework A optimum requires 87,660 additional reviews, representing a 480.3% increase in review capacity relative to the elbow. This additional capacity increases EFL capture by only 25.6 percentage points, from 64.7% to 90.3%. In other words, the organisation must increase review capacity by almost five times to capture the remaining 25.6% of EFL. This illustrates the strong diminishing returns associated with expanding capacity beyond the elbow.

The same pattern is observed across the other manual review cost scenarios. At C_MR = USD 5, the elbow requires approximately 14,500 reviews (2.46% of transactions), compared with 74,690 reviews (12.65%) at the Framework A optimum. This represents 415.1% more reviews to reach the unconstrained optimum. At C_MR = USD 10, the elbow requires 10,500 reviews (1.78%), whereas the unconstrained optimum requires 44,785 reviews (7.58%), meaning that capacity must increase by 326.5%. Similarly, at C_MR = USD 15, capacity increases from 8,000 reviews (1.35%) at the elbow to 32,495 reviews (5.50%) at the optimum, an increase of 306.2%. Finally, at C_MR = USD 20, the elbow requires only 7,500 reviews (1.27%), compared with 25,620 reviews (4.34%) at the Framework A optimum — 241.6% more reviews.

This behaviour is also reflected in the EFL capture curve. Because transactions are ordered from highest to lowest EFL, the ranking concentrates the largest expected fraud losses at the beginning of the review queue. Consequently, a relatively small proportion of transactions captures a disproportionately large share of the available economic exposure. As lower-ranked transactions are progressively added, each additional review contributes less expected financial benefit.

Overall, Framework A provides the economic boundary for manual review, identifying which review volumes remain economically justified under each cost scenario. Framework B then translates this economic framework into an operational prioritisation strategy by ranking transactions according to their Expected Financial Loss. The elbow criterion provides a practical way of determining how much of the available review capacity should actually be deployed, balancing economic benefit against operational effort. Together, the two frameworks connect economic selection, transaction-level prioritisation and capacity planning, providing decision-makers with financially grounded guidance on both which transactions to review and how many to review.

Concluding remark¶

This analysis demonstrates that the objective of a cost-sensitive fraud detection system is not merely to maximise predictive performance, but to support economically and operationally informed decision-making. By combining predictive modelling with Expected Financial Loss, the framework quantifies the economic value of reviewing individual transactions and identifies the volume of reviews that is economically justified under different manual review costs.

Framework B extends this analysis to capacity-constrained environments by prioritising transactions according to their Expected Financial Loss, ensuring that limited investigation capacity is allocated to transactions with the greatest potential financial impact. The elbow criterion further provides a practical operating point by identifying where expanding review capacity begins to yield substantially lower marginal returns.

Overall, the proposed framework connects fraud prediction, economic optimisation, transaction prioritisation, and operational capacity planning, providing decision-makers with financially grounded guidance on both which transactions to review and how much review capacity to deploy.
